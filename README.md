# check-ref
面向 Word 和 LaTeX 论文的只读参考文献核查 Skill：辅助核对文献元数据与引文主张，生成 Markdown 审计报告，不修改原稿和参考文献文件。  英文简介： A read-only reference-checking skill for Word and LaTeX manuscripts. It checks bibliography metadata and citation-claim support, then generates a Markdown audit report without modifying the original files.
